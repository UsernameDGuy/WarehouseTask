To run the program, you will require the following package:

Microsoft.Data.SqlClient

The SQL Program was built to run on a Microsoft Server Express server running on a local computer.

Assuming Microsoft Server Express 2025 has been installed on the local computer, the following command: 'sqlcmd -S {Your_Laptop_Name_Here} -No -E' will activate the server.

Run the sql file under Microsoft SQL Server Management System after connecting to local computer.

Simply cd to the location of WarehouseTask.exe in command prompt and use it as follows:

WarehouseTask.Exe {Number within selectable range}
